# Eventos (diferido)

Métricas que necesitan una **capa de eventos derivados** (acciones on-ball) y la dirección de ataque. Se difieren respecto de las métricas de estructura.

- [SPADL (acciones)](spadl.md) — el formato de acciones que derivamos del tracking.
- [PPDA y line-breaking](ppda-y-line-breaking.md) — presión y pases que rompen líneas.
