# Sportify App — Foundation Scaffold Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up `sportify-app/` — an Expo + React Native + TypeScript mobile client skeleton that boots in Expo Go on iOS, has green tests, a data-layer seam, and a configured (but not executed) EAS release pipeline.

**Architecture:** A single Expo (managed) app using Expo Router for file-based navigation, isolated as a top-level sibling to `sportify-game-reconstruction/`. Features depend on repository *interfaces* (the "data-layer seam"); v0 ships only an in-memory implementation so the app runs and tests without a backend. No product features beyond one placeholder screen.

**Tech Stack:** Expo (managed), React Native, TypeScript (strict), Expo Router, pnpm (Corepack, `node-linker=hoisted`), Jest + React Native Testing Library, Maestro, EAS, GitHub Actions.

**Spec:** [`docs/superpowers/specs/2026-07-05-sportify-app-foundation-design.md`](../specs/2026-07-05-sportify-app-foundation-design.md)

## Global Constraints

- **Language:** TypeScript with `"strict": true`.
- **Package manager:** pnpm, via Corepack. `sportify-app/.npmrc` MUST contain `node-linker=hoisted` (React Native requirement) **before** the first `pnpm install`.
- **App display name:** `Sportify`.
- **Bundle id / Android package:** `com.implacables.sportify` (working default; changeable until first store submission).
- **Navigation:** Expo Router (routes under `app/`).
- **Isolation:** Do NOT modify anything under `sportify-game-reconstruction/`, the root `scripts/`, or the **root** `.gitignore`. All Node/Expo artifacts are ignored by the app-local `.gitignore`.
- **Branch:** all work lands on `feature/sportify-app-scaffold` (per `docs/branching-strategy.md`).
- **Run target for verification:** iOS via **Expo Go on a physical phone** (no iOS simulator on Linux; Android deferred).
- **EAS:** configure offline files only. Do **not** run `eas build`, `eas submit`, or `eas update` in this plan.
- **All commands run from `sportify-app/`** unless stated otherwise.

### Task 7: CI workflow (typecheck + lint + test)

Add a GitHub Actions workflow that runs on PRs touching `sportify-app/`.

**Files:**
- Create: `.github/workflows/app-ci.yml`

**Interfaces:**
- Consumes: `pnpm` scripts `typecheck`, `lint`, `test`.
- Produces: a CI gate (runs on GitHub; not executed locally).

- [ ] **Step 1: Create the workflow**

Create `.github/workflows/app-ci.yml` (at the repo root):
```yaml
name: app-ci

on:
  pull_request:
    paths:
      - "sportify-app/**"
      - ".github/workflows/app-ci.yml"

defaults:
  run:
    working-directory: sportify-app

jobs:
  check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: pnpm
          cache-dependency-path: sportify-app/pnpm-lock.yaml
      - run: pnpm install --frozen-lockfile
      - run: pnpm typecheck
      - run: pnpm lint
      - run: pnpm test
```
